# Deep track

This track prepares you to read the repository, reason about lifecycle and state, design a dynamic plugin, and assess enterprise and market claims. Each module begins with a concrete case, builds a provisional model, explains the mechanism step by step, and then states where the model stops being reliable.

## Refreshed prerequisites

Modules 1, 2, and 4 explicitly teach the agent loop, service registry and dependency injection, scoped lifecycle, and event sourcing. The track is independent of the quick track.
