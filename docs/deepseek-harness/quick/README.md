# Quick track

This track builds a compact but operational model of DeepSeek Harness. After four modules, you should be able to explain what the Harness owns, trace one turn, distinguish Host from Agent Preset composition, and interpret market evidence without confusing attention with adoption.

## Refreshed prerequisites

The first three modules refresh the LLM agent loop, service discovery, scoped lifecycle, and event-sourced state in the context where DeepSeek Harness uses them. No prior completion of the deep track is required.
